# Provisional synthetic retrieval evaluation

The dataset [retrieval-cases-v1.json](../../evals/retrieval-cases-v1.json) contains 20 development and 10 holdout-labeled queries. Cases and expected sources were authored as synthetic draft labels and have not been independently reviewed by a human. Development and holdout source groups are disjoint, but the author had access to all four fixture articles when writing the queries. The split is not a blind real-world holdout. Dataset SHA-256 is `b763acd403ed766b941dd6203ffbf6ab90be3a54c15e643a9afe3ec6ea0a1c24`.

From backend, run `uv run --locked python ../scripts/evaluate_retrieval.py --split dev --mode keyword`. Choose `holdout` explicitly for the other group. The `vector` mode uses the pinned local `all-minilm:22m` model and requires a running Ollama server. Each run creates and removes an isolated synthetic PostgreSQL schema. Outputs include per-case IDs, result counts, hit flags, timing, model digest and dataset hash.

On 2026-11-09 with PostgreSQL 17.11, keyword Hit@5 was 19/20 on development and 10/10 on the holdout-labeled group. The missed development case was dev-19. Vector Hit@5 was 20/20 and 10/10 respectively with model digest `1b226e2802dbb772b5fc32a58f103ca1804ef7501331012de126ab22f67475ef`. Vector search returned all four articles for every case because k=5 exceeds corpus size, so this metric cannot distinguish vector ranking quality. The wording closely follows the source material and these figures are functional observations, not accuracy or generalization estimates.

The first parallel vector attempts failed during a cold model start at the existing provider timeout; sequential runs after loading succeeded. The vector holdout-labeled group was executed twice because the first output was truncated. No query or retrieval changes were made between those runs, but the data has been exposed and should not be treated as an untouched holdout. Independent human label review, a larger corpus, meaningful ranking metrics, claim support, refusal, latency controls and adversarial evaluation remain necessary.

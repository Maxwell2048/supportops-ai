# Local full-stack and recovery verification

On 2026-11-09, Docker Engine 29.7.2 built and started an isolated local project with PostgreSQL 17, migrations, API, mock worker and nginx-served frontend. A second clean isolated project reproduced the sequence. The web endpoint, readiness, synthetic requester and manager logins, ticket creation, mock-worker no-evidence result and human rejection all passed.

The backup tool created a PostgreSQL custom-format archive and restored it to a newly created separate database. Counts and deterministic row fingerprints matched across 15 business and migration tables. The archive used only synthetic test data. A reproducible stack-check script repeats this smoke and recovery exercise. The full backend suite passed 306 tests with zero skips, including tests that reject backup overwrite and unsafe restore names. Frontend npm ci and build passed.

The local test does not establish production backups, recovery cutover, Azure deployment, high availability, real-model container networking or image-tag immutability. The CI stack job is checked separately on the published commit.

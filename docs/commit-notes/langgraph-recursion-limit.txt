fix(analysis): turn the LangGraph recursion backstop into a defined job failure

A teammate review found that the LangGraph orchestration could crash the worker. When the recursion_limit backstop fires, LangGraph raises GraphRecursionError, a RuntimeError that execute_job does not catch, so the exception would escape execute_job and the worker loop. agent_graph.gather now converts it into ToolStopped("tool_loop_limit", trace). execute_job already records a ToolStopped as a failed, non-transient job that keeps the trace gathered so far, so the job ends with a defined error code and the calls that actually ran. The server does not add its baseline search after a routing defect, and retrying would repeat the same defect. The conversion lives in agent_graph, so the default hand-written path still imports no LangGraph module.

While I was writing the bound test, I measured the step count. The longest normal run takes 7 node steps, but LangGraph also counts the input step, so it needs a limit of 8. The configured 2 * MAX_ROUNDS + 2 is exactly that minimum, not a limit with slack. I corrected the code comment, and a test now pins that the worst case passes at 8 and fires at 7.

I verified with cd backend; uv run pytest: 113 passed and 265 skipped. All skips are PostgreSQL integration tests: TEST_DATABASE_URL was unset, the Docker engine was not running and nothing listened on the configured local PostgreSQL port. Three new unit tests force the backstop through gather and through execute_job with fake database access, and check the exact bound. Replacing the except clause with an unrelated exception made all three fail. The fresh-interpreter default-path test still passes. I added a PostgreSQL case that checks the stored failed job and its trace, but like the 20 tool-loop integration cases it did not run in this session. The repository language check passed.

Limitations: no database result, real-model run or remote CI is claimed for this change. Other unexpected exceptions in execute_job still propagate to the worker as before; this change covers only the LangGraph backstop.
